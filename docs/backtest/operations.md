# V3 回测运行手册

回测命令只读本地 `data/sequoia_v3.db`，不会访问网络。运行前应完成对应历史区间的
行情回填、质量处理和 QFQ 因子刷新。

回测前只需执行统一数据同步：

```bash
uv run python main.py data sync
```

该命令在全市场行情成功后自动检查中证全指缺口，只从最早缺失交易日开始增量补齐，保存
独立 `BENCHMARK_BARS` 批次、原始响应证据和 canonical 行情；不会把基准批次记作
全市场 `DAILY_SNAPSHOT`。无缺口时不会请求基准源。

## 数据审计

```bash
uv run python main.py backtest audit --start 2025-01-01 --end 2025-12-31
```

审计检查区间是否存在完整交易日，并对首尾边界构建 121 日研究窗口。退出码 `0` 表示
边界质量闸门通过，退出码 `1` 表示数据不具备回测条件。执行期间会持续显示完整交易日
查询、全库质量审计和边界快照检查进度；完成后默认输出简洁 Summary。

脚本或排障需要完整结构化结果时使用：

```bash
uv run python main.py backtest audit \
  --start 2025-01-01 --end 2025-12-31 --json
```

`--json` 会关闭动态进度，只向标准输出写入机器可读 JSON。

## 信号回测

```bash
# 默认策略，评价信号后 1/5/10/20 个完整交易日
uv run python main.py backtest run --start 2025-01-01 --end 2025-12-31

# 单策略和自定义前瞻周期
uv run python main.py backtest run \
  --start 2025-01-01 \
  --end 2025-12-31 \
  --strategy rps \
  --horizon 5 \
  --horizon 20 \
  --output reports/backtest-rps-2025.json

# 自定义组合执行参数
uv run python main.py backtest run \
  --start 2025-01-01 \
  --end 2025-12-31 \
  --holding-period 10 \
  --exit-retry-days 5 \
  --initial-cash 1000000 \
  --max-positions 10 \
  --commission-rate 0.0003 \
  --minimum-commission 5 \
  --slippage-bps 2
```

运行期间会动态显示六个阶段：解析日期、批量准备数据、逐日运行策略、评价前瞻收益、模拟
账户、写入报告。完成后默认显示：

- 回测区间、数据覆盖率、信号数量和计算异常；
- 各策略在 1/5/10/20 日观察期的平均涨跌、中位数和上涨比例；
- 初始资金、期末权益、累计盈亏、最大回撤、波动率、Sharpe、Sortino 和交易成本；
- 已平仓交易胜率、平均盈利/亏损、盈亏比、区间及年化双边换手率；
- 自然年度组合收益、同期沪深300/中证全指收益和两组算术超额收益；
- 买卖次数、拒绝/延期订单、未成交原因和期末未平仓；
- 面向非专业用户的通俗解释和短样本提示。

自动化脚本只需要机器可读结果时增加 `--json`：

```bash
uv run python main.py backtest run \
  --start 2025-01-01 --end 2025-03-31 \
  --strategy ma_volume --json
```

`--json` 会关闭动态进度和 Summary；完整明细仍写入 `--output` 指定的报告。

结束日之后必须还有足够的完整交易日覆盖最大 `--horizon`。例如包含 `--horizon 20`
时，本地数据库至少需要结束日之后 20 个完整交易日。

运行时会先执行一次 V3 全库质量审计，再批量载入回测区间所需行情和因子。大型本地库的
首次审计可能需要数分钟；历史快照不会再按交易日重复扫描 SQLite。

`shakeout` 和 `limit_down` 仍然默认禁用，只能通过 `--strategy` 显式运行；报告会保留其
未完成独立验证的风险备注。

## 结果解释

报告同时保留两种口径：

- 信号评价：信号日收盘价到第 N 个完整交易日收盘价，用于比较信号本身；
- 组合模拟：T+1 开盘入场、固定持有期、100 股整数手、仓位、费用和受阻订单。

组合模拟仍基于日线，无法证明盘中真实排队成交；没有完整历史 ST 和板块涨跌停证据时，
一字板采用保守方向判断。结果不能解释为实盘预期或未来收益。

组合胜率只统计已完成买入和卖出的交易，并按成交价扣除佣金、印花税后判断盈亏；它与
信号评价中的“上涨比例”不是同一个指标。盈亏比是平均盈利除以平均亏损绝对值。双边
换手率以全部买卖成交额之和除以平均账户权益，年化值再按 252 个交易日折算。

Sharpe 使用零无风险利率；Sortino 使用零目标收益率且只惩罚下行波动。自然年度未覆盖
完整 1 月至 12 月时标记为“部分年度”。双基准固定使用本地 `SSE:000300` 和
`SSE:000985` canonical 收盘价，并与组合权益采用相同首尾日期；任一必要日期缺失时
整次回测停止。
