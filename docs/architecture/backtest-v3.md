# V3 回测框架

## 策略与执行边界

现有策略继续只接收 `ResearchSnapshot` 并返回 `StrategyResult`。持有期、费用、仓位和
成交约束全部位于独立 `PortfolioSimulator`，不进入策略公式。

## 时间边界

- T 日策略只接收 `as_of_date=T` 的研究快照，快照内不得出现 T 日之后的行情。
- 前瞻 N 日收益定义为：T 日 QFQ 收盘价到第 N 个完整交易日 QFQ 收盘价的变化率。
- 前瞻行情只用于信号产生后的评价，不能反馈给 T 日策略。
- 请求结束日之后必须至少存在最大前瞻周期所需的完整交易日，否则整体停止。
- 后续证券缺少行情时记录 `NO_FORWARD_BAR`，不使用旧价格或零收益代替。

## 数据质量

`BacktestDataService` 只读取本地 V3 SQLite，并复用 `ResearchDataService` 的统一研究日、
证券生命周期、代码别名、QFQ 因子和最低覆盖率闸门。每个历史日均单独经过质量检查；
任一必要快照失败时，整次回测失败，不输出成功报告。

回测启动后只执行一次基础全库审计，并一次批量读取整个所需区间的证券生命周期、行情和
因子证据。各历史日快照在内存中按日期切片，仍按当日有效期、因子证据日、历史窗口和
最后行情日逐项校验。批量加载是查询优化，不放宽 point-in-time 或覆盖率规则。

完整交易日来自 `ingestion_batches` 中状态为 `COMPLETE` 的 `DAILY_SNAPSHOT` 批次。
批量原始行情和因子证据在单次进程内复用；逐日快照按需生成并释放，避免长区间保存所有
全市场历史窗口。该内存策略不会改变数据选择或质量语义。

## 输出契约

JSON 报告包含：

- 配置、代码 Git revision、数据库路径和生成时间；
- 信号日期、策略、证券、信号收盘价、规则依据和快照覆盖率；
- 每个前瞻周期的评价日期、收盘价、收益或排除原因；
- 按策略和周期统计的样本数、排除数、平均收益、中位数收益和胜率；
- 独立策略组合的订单、费用、持仓、每日权益、风险与交易质量指标；
- 同期沪深300和中证全指基准、自然年度收益及两组算术超额收益；
- 明确记录成交假设和风险边界，不把模拟结果描述为实盘收益。

报告不保存密钥、环境变量、原始 payload 或通知配置。

## 成交与账本模型

- 每个策略使用独立初始资金，策略之间不共享持仓或现金。
- T 日收盘后产生信号，T+1 开盘尝试买入；只买 100 股整数手。
- 默认等权容量为组合权益除以最大持仓数，已有持仓不重复加仓。
- 同日候选超过剩余仓位时，有候选分数的策略按分数从高到低选取，同分再按
  `instrument_id` 排序；没有分数的策略仍按 `instrument_id` 确定性选取。候选分数只用于
  同策略相对排序，不表示收益概率，也不能跨策略比较。
- 达到最大持仓数、资金不足、无当日行情或一字上涨锁定时，买单明确拒绝。
- 入场后固定持有 N 个完整交易日，随后开盘卖出；无行情或一字下跌锁定时延期，
  后续交易日在 `exit_retry_days` 尾部窗口内继续尝试；耗尽后保留为期末未平仓。
- 买卖双边收取佣金并支持最低佣金；滑点以单边基点配置。
- 印花税只在卖出时收取：2023-08-28 前为成交金额 0.1%，自该日起为 0.05%。依据
  《中华人民共和国印花税法》和财政部、税务总局公告 2023 年第 39 号。
- 无当日行情的持仓按最近有效收盘价估值，不把停牌日伪造成零价格。

组合报告包含总收益、年化收益、年化波动率、零无风险利率 Sharpe、零目标收益率
Sortino、最大回撤、自然年度收益、已平仓交易胜率、平均盈亏、盈亏比、双边换手率、
费用、订单状态、每日权益和期末未平仓持仓。

基准固定读取 `SSE:000300`（沪深300）和 `SSE:000985`（中证全指）的 canonical
收盘价。组合与基准使用相同首尾交易日；任一基准缺少必要交易日时停止回测。超额收益
使用“组合收益减对应基准收益”的算术口径。中证全指由统一 `data sync` 编排按缺口通过
腾讯 K线增量同步；基准原始行情、来源URL、校验和和独立批次均保留，回测运行时不联网。

## 模型限制

- 日线数据不能证明盘中排队成交，开盘价成交只是明确的模拟假设。
- 当前没有完整 point-in-time ST 标识和板块涨跌停规则；一字板使用保守的同价 OHLC 与
  前收方向判断，不宣称精确复原交易所撮合。
- 账本使用 QFQ 价格形成归一化资金曲线；它适合比较策略，不等同于券商账户对分红、送转、
  配股和最低佣金的逐笔现金结算。
- 尚未加入分红现金流独立核算、冲击成本或成交量容量模型。
- 不包含券商、自动下单、在线数据源或实盘路径。
