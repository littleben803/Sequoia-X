# Sequoia-X V3 数据底座 PRD

## 目标

建立面向股票、基金、ETF、债券、可转债、REITs 等交易所证券的原始数据底座。
当前 MVP 仍只做 A 股研究，但不得因为当前策略不使用其他证券而丢弃盘后包记录。

## 用户价值

- 全市场历史回填从逐股票请求改为逐交易日下载。
- 中断后按已完成交易日续跑。
- 每条行情可追溯到 Provider、下载批次和原始记录。
- 主源失败时明确降级；部分成功不冒充全品种完整成功。
- 终端事件与未来 Web UI 共用结构化模型。

## 本阶段范围

- AStockDataProvider 主源。
- BaostockProvider 降级源。
- V3 SQLite Schema、回填、增量、审计和终端展示。
- 保存原始不复权行情和证券发现记录。

## 非本阶段范围

- 不修改选股公式。
- 不将 V3 数据直接接入策略。
- 不接入研报、新闻、财务、资金流等外围能力。
- 不做券商、交易或下单。

## 成功标准

一个交易日盘后包中的全部有效证券均可幂等落库；不同来源互不覆盖；任务可续跑；
失败、降级、停牌和无法解释的缺口具有不同状态；审计结果不会输出误导性的“全部完成”。
